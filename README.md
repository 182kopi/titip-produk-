# TITIPKU - Aplikasi Titip Produk Retail
Aplikasi konsinyasi untuk nitip produk ke banyak toko.

## Cara Jalanin
1. Download folder ini
2. Buka `index.html` di Chrome (double klik)
3. Tidak perlu install, tidak perlu internet (kecuali backup Drive)

## Alur Pakai
1. Tambah Toko di menu Data Toko (atur komisi, misal 20%)
2. Tambah Produk di menu Data Produk (modal, jual, stok gudang)
3. Menu Titip Produk: Pilih Toko + Produk + Jumlah → Stok gudang berkurang, stok toko bertambah
4. Menu Kasir: Pilih Toko → Produk di toko itu muncul → Masuk keranjang → Checkout
5. Menu Setoran: Toko setor hasil jualan → Piutang otomatis berkurang
6. Menu Retur: Produk rusak / tidak laku balik ke gudang
7. Menu Laporan: Lihat omzet, laba, komisi per toko

## Backup
Menu Backup → Download Backup → Upload ke Google Drive
Ganti HP / Laptop → Restore file backup → Data balik semua# titip-produk-
